## Projetos em destaque

### [Eco](https://github.com/Pedro3495/eco)

Aplicação financeira em desenvolvimento, com foco em organização de contas, categorias, transações e relatórios.  
**Stack:** Java, Spring Boot, PostgreSQL, React, Next.js, TypeScript

**Destaques técnicos**

- Modelagem de domínio para contas, categorias e transações.
- API REST com filtros, paginação e regras de negócio.
- Frontend conectado a dados reais e preparado para evoluir como PWA.
- Evolução gradual com testes e boas práticas de backend.

### Sistema de Gestão de Ativos

Sistema web desenvolvido para ambiente corporativo, usado para centralizar o controle de ativos físicos da empresa com rastreamento e interface administrativa.  
**Stack:** React, Next.js, Supabase  
**Contexto:** sistema interno em produção

Projeto web voltado para gestão de filas e atendimento, com telas para usuário, administrador e fluxo de atendimento.  
**Foco:** usabilidade, organização de interface e experiência prática de produto.
